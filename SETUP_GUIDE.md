# 🚀 Guida Rapida

## Installazione (5 min)

1. **Aggiungi Repository**
   ```
   Impostazioni → Componenti aggiuntivi → ⋮ → Repository
   https://github.com/MLnalis/ha-easyproxy
   ```

2. **Installa**
   ```
   Componenti aggiuntivi → EasyProxy → Installa
   ```

3. **Configura**
   - Cambia `api_password` da `ep`
   - Clicca **Salva**

4. **Avvia**
   - Clicca **Avvia**
   - Attendi 30-60 sec

5. **Accedi**
   ```
   http://[IP-HA]:7860
   ```
